# 볼트빈 커피 퀴즈

코디세이 Python·Git 입문 미션으로 만든 터미널 퀴즈입니다. 커피와 카페 음료에 관한 기본 문제 여섯 개를 풀고, 나만의 문제를 더할 수 있습니다.

## 주제를 고른 이유

볼트빈커피 홈페이지에서 카페 메뉴를 소개하는 모습을 보고 주제를 정했습니다. 아메리카노와 카페라테처럼 익숙한 음료에서 시작해 에스프레소 추출과 원두 로스팅 같은 기초 개념도 익힐 수 있도록 문제를 구성했습니다. [주제 참고 · 볼트빈커피](https://voltbean.co.kr/)

## 실행 방법

Python 3.10 이상이 필요합니다. Python 표준 라이브러리만 사용합니다.

```sh
git clone https://github.com/pjmin19/codyssey-voltbean-quiz.git
cd codyssey-voltbean-quiz
python main.py
```

Windows에서 `python` 명령 대신 `py -3.10 main.py`를 사용할 수 있습니다. 메뉴 번호를 입력하고 Enter를 누릅니다.

## 기능

| 번호 | 메뉴 | 동작 |
| --- | --- | --- |
| 1 | 퀴즈 풀기 | 등록된 문제를 모두 출제합니다. 문제마다 정오답을 알려주고 마지막에 정답 수와 점수를 보여줍니다. |
| 2 | 퀴즈 추가 | 문제, 선택지 네 개, 정답 번호를 입력하면 저장합니다. |
| 3 | 퀴즈 목록 | 등록된 문제의 개수와 질문을 보여줍니다. |
| 4 | 점수 확인 | 지금까지 끝까지 푼 라운드의 최고 점수를 보여줍니다. |
| 5 | 종료 | 저장할 변경이 남아 있으면 저장하고 종료합니다. |

점수는 `정답 수 × 100 ÷ 출제 수`의 소수점 아래를 버려 계산합니다. 빈 입력, 숫자가 아닌 값, 범위를 벗어난 번호에는 안내를 표시하고 다시 입력받습니다. 입력이 끊기거나 Ctrl+C를 누르면 안내 후 종료합니다. 중간에 멈춘 라운드는 점수에 반영하지 않습니다.

## 파일 구조

| 파일 | 역할 |
| --- | --- |
| `main.py` | 시작 파일. `QuizGame`이 메뉴, 입력, 풀이, 점수, 저장을 관리합니다. |
| `quiz.py` | `Quiz`가 한 문제와 네 선택지, 정답 번호를 가지고 문제 출력과 정답 판정을 담당합니다. |
| `questions.py` | 처음 실행할 때 사용하는 커피 퀴즈 여섯 개를 정의합니다. |
| `state.json` | 프로젝트 루트에 실행 중 생성되는 개인 퀴즈와 최고 점수 파일입니다. |
| `docs/screenshots/` | 실행 환경, 콘솔 실행, Git 이력 화면입니다. |

## 저장 데이터

`state.json`에는 UTF-8로 다음 두 값을 기록합니다.

- `quizzes`는 문제 목록입니다. 문제마다 `question`(질문), `choices`(문자열 네 개), `answer`(1~4 중 하나의 정답 번호)가 있습니다.
- `best_score`는 완료한 라운드 중 최고 점수입니다. 범위는 0~100이며, 아직 끝까지 푼 라운드가 없으면 `null`입니다.

첫 실행에는 기본 퀴즈를 사용합니다. 문제를 추가하거나 최고 점수를 갱신하면 저장합니다. JSON 문법이나 데이터 형식이 손상된 경우에는 안내를 표시하고 기본 데이터로 다시 저장합니다. `state.json`은 Git에서 제외합니다.

한 폴더에서는 한 번에 게임 한 개를 실행하세요. 여러 창에서 동시에 실행하면 마지막으로 저장한 창의 데이터가 파일에 남습니다.

## Git 실습 기록

퀴즈 풀기는 `codex/quiz-play` 브랜치에서 작업하고 `main`에 병합했습니다. 개발과 자료 업로드를 마친 뒤 공개 저장소를 다른 폴더에 `git clone`했습니다. 이 실습 기록은 복제본에서 추가하고 커밋한 뒤 `git push`로 올렸습니다. 처음 작업하던 폴더에서 `git pull --ff-only`로 받아 확인했습니다.
