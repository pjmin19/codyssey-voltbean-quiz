# 볼트빈 커피 퀴즈

코디세이 Python·Git 입문 미션으로 만든 터미널 퀴즈입니다. 커피와 카페 음료에 관한 기본 문제 여섯 개를 풀고, 나만의 문제를 더할 수 있습니다.

## 주제를 고른 이유

볼트빈커피 홈페이지에서 카페 메뉴를 소개하는 모습을 보고 주제를 정했습니다. 아메리카노와 카페라테처럼 익숙한 음료에서 시작해 에스프레소 추출과 원두 로스팅 같은 기초 개념도 익힐 수 있도록 문제를 구성했습니다. [주제 참고 · 볼트빈커피](https://voltbean.co.kr/)

## 실행 방법

Python 3.10 이상이 필요합니다. Python 표준 라이브러리만 사용합니다.

```sh
git clone https://github.com/pjmin19/codyssey-voltbean-quiz.git
cd codyssey-voltbean-quiz
python main.py
```

Windows에서 `python` 명령 대신 `py -3.10 main.py`를 사용할 수 있습니다. 메뉴 번호를 입력하고 Enter를 누릅니다.

## 기능

| 번호 | 메뉴 | 동작 |
| --- | --- | --- |
| 1 | 퀴즈 풀기 | 등록된 문제를 모두 출제합니다. 문제마다 정오답을 알려주고 마지막에 정답 수와 점수를 보여줍니다. |
| 2 | 퀴즈 추가 | 문제, 선택지 네 개, 정답 번호를 입력하면 저장합니다. |
| 3 | 퀴즈 목록 | 등록된 문제의 개수와 질문을 보여줍니다. |
| 4 | 점수 확인 | 지금까지 끝까지 푼 라운드의 최고 점수를 보여줍니다. |
| 5 | 종료 | 저장할 변경이 남아 있으면 저장하고 종료합니다. |

점수는 `정답 수 × 100 ÷ 출제 수`의 소수점 아래를 버려 계산합니다. 빈 입력, 숫자가 아닌 값, 범위를 벗어난 번호에는 안내를 표시하고 다시 입력받습니다. 입력이 끊기거나 Ctrl+C를 누르면 안내 후 종료합니다. 중간에 멈춘 라운드는 점수에 반영하지 않습니다.

## 파일 구조

| 파일 | 역할 |
| --- | --- |
| `main.py` | 시작 파일. `QuizGame`이 메뉴, 입력, 풀이, 점수, 저장을 관리합니다. |
| `quiz.py` | `Quiz`가 한 문제와 네 선택지, 정답 번호를 가지고 문제 출력과 정답 판정을 담당합니다. |
| `questions.py` | 처음 실행할 때 사용하는 커피 퀴즈 여섯 개를 정의합니다. |
| `state.json` | 프로젝트 루트에 실행 중 생성되는 개인 퀴즈와 최고 점수 파일입니다. |
| `docs/screenshots/` | 실행 환경, 콘솔 실행, Git 이력 화면입니다. |

### 클래스를 나눈 이유

`Quiz`는 한 문제의 질문·선택지·정답을 한 객체에 묶습니다. 문제 출력과 정답 판정은 각 객체의 `show()`와 `is_correct()`에서 처리합니다. 문제를 여러 값과 독립 함수로 관리하면 호출부가 함수마다 필요한 값을 골라 전달해야 하므로, 문제 형식을 바꿀 때 값이 어디서 쓰이는지 함께 살펴야 합니다. `QuizGame`은 전체 문제 목록과 최고 점수를 관리하므로, 메뉴나 저장 방식을 바꿀 때 개별 문제의 정답 판정은 그대로 사용할 수 있습니다.

## 저장 데이터

`state.json`에는 UTF-8로 다음 두 값을 기록합니다.

- `quizzes`는 문제 목록입니다. 문제마다 `question`(질문), `choices`(문자열 네 개), `answer`(1~4 중 하나의 정답 번호)가 있습니다.
- `best_score`는 완료한 라운드 중 최고 점수입니다. 범위는 0~100이며, 아직 끝까지 푼 라운드가 없으면 `null`입니다.

첫 실행에는 기본 퀴즈를 사용합니다. 문제를 추가하거나 최고 점수를 갱신하면 저장합니다. JSON 문법이나 데이터 형식이 손상된 경우에는 안내를 표시하고 기본 데이터로 다시 저장합니다. `state.json`은 Git에서 제외합니다.

한 폴더에서는 한 번에 게임 한 개를 실행하세요. 여러 창에서 동시에 실행하면 마지막으로 저장한 창의 데이터가 파일에 남습니다.

JSON은 사람이 텍스트 편집기로 읽을 수 있고, 키 이름과 목록 구조가 파일에 드러납니다. 한 줄에 여러 값을 구분 기호로 나열하는 방식은 선택지 네 개가 어느 문제에 속하는지 따로 해석해야 합니다. JSON에서는 한 문제를 하나의 객체로 묶어 선택지 목록을 안에 넣고, 최고 점수는 문제 목록과 별도의 필드에 둡니다. Python 표준 라이브러리 `json`으로 읽고 쓸 수 있으며, 한글은 UTF-8 문자 그대로 기록합니다.

### 데이터가 많아질 때

시작할 때는 JSON 파일 전체를 읽어 문제 객체를 메모리에 올립니다. 문제를 추가하거나 최고 점수를 갱신할 때도 현재 문제 목록과 점수를 새 임시 파일에 모두 쓴 뒤 `state.json`을 교체합니다. 그래서 문제 수와 파일 크기가 늘면 시작 시간, 저장 시간, 메모리 사용량도 늘어납니다. 이 미션처럼 문제 수가 적을 때는 한 파일로 충분합니다. 일부 문제만 빠르게 검색하거나 수정해야 할 만큼 데이터가 커지면 SQLite에 문제를 행 단위로 저장하는 방법을 검토할 수 있습니다.

### 저장 파일 백업과 복원

정상적으로 저장된 문제와 점수를 보관하려면 게임을 종료하고 프로젝트 폴더에서 다음 PowerShell 명령을 실행합니다. 복사본 이름에 날짜와 시간이 들어가므로 이전 백업도 함께 보관할 수 있습니다.

```powershell
$backup = "state.$(Get-Date -Format yyyyMMdd-HHmmss-fff).bak.json"
Copy-Item -LiteralPath ./state.json -Destination $backup -ErrorAction Stop
```

손상된 파일로 실행하면 프로그램이 기본 문제로 초기화합니다. 추가한 문제와 최고 점수를 되찾으려면 게임을 종료한 뒤 정상 백업을 `state.json`으로 복사합니다. 아래의 `$backup`은 복원할 백업 파일의 이름입니다. 새 PowerShell 창이라면 그 파일명을 먼저 `$backup`에 지정하세요.

```powershell
Copy-Item -LiteralPath $backup -Destination ./state.json -ErrorAction Stop
python main.py
```

메뉴 3번에서 추가한 문제를, 4번에서 최고 점수를 확인합니다. 개인 저장 파일과 `state.*.bak.json` 백업 파일은 Git에 포함하지 않습니다.

## Git 실습 기록

### 커밋 단위와 메시지

메뉴, 퀴즈 풀이, 저장처럼 한 기능을 완성하고 확인한 뒤 해당 변경을 한 커밋에 담았습니다. 메시지는 `유형: 바꾼 내용` 형식을 사용합니다. 기능 추가에는 `Feat`, 오류 수정에는 `Fix`, 문서 변경에는 `Docs`, 브랜치 병합에는 `Merge`를 씁니다. 실제 메시지 예시는 `Feat: 메뉴와 숫자 입력 오류 처리 구현`, `Feat: UTF-8 JSON 저장과 재시작 및 손상 복구 지원`, `Docs: 퀴즈 주제와 실행 방법, 기능, 저장 스키마 정리`입니다.

### 브랜치와 병합

퀴즈 풀이 기능을 만드는 동안 `main`의 메뉴와 기본 문제를 실행할 수 있도록 `codex/quiz-play` 브랜치에서 작업했습니다. 그 브랜치에서 정답 입력과 점수 계산을 확인한 뒤 `main`에 병합했습니다. `git merge --no-ff codex/quiz-play`로 병합 커밋을 남겨 기능이 분리되어 개발된 이력을 확인할 수 있습니다. [병합 커밋 `90b09e7`](https://github.com/pjmin19/codyssey-voltbean-quiz/commit/90b09e7d1ef6bdf5ccc131ae5936e9f69e7a7f86)

```text
*   90b09e7 Merge: 퀴즈 풀기 브랜치를 main에 병합
|\
| * 0f27e3b Feat: 풀이 진행과 정오답 안내 및 결과 계산 구현
|/
* 3944496 Feat: 커피와 카페 음료 기본 퀴즈 여섯 문제 작성
```

### 커밋 수와 원격 저장소 확인

미션 완성본 `d21ea5b`까지의 커밋은 총 **13개**입니다. 병합 커밋 1개를 빼면 파일을 변경한 커밋은 **12개**입니다. `git rev-list --count d21ea5b`와 `git rev-list --no-merges --count d21ea5b`로 각각 확인할 수 있습니다. [GitHub 커밋 이력](https://github.com/pjmin19/codyssey-voltbean-quiz/commits/main/)

공개 저장소를 별도 폴더에 `git clone`한 뒤, 복제본에 실습 기록을 추가한 커밋 `d21ea5b`를 `git push`했습니다. 원래 폴더에서 `git pull --ff-only`를 실행해 같은 커밋과 README 변경을 확인했습니다.
